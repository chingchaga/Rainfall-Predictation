Research goals: Use radiosonde relative humidity (RH) measured at multiple pressure levels (1000–150 hPa) to: Predict the occurrence of rainfall (yes/no) Predict the rainfall amount (mm/h) when rain occurs?

Why this is useful? Vertical RH datas encode the atmosphere’s moisture structure. These factors are directly tied to cloud formation and precipitation. It offers a low‑cost complement to radar/satellite for short‑lead forecasting (e.g., nowcasting, drainage operations, outdoor event planning).
